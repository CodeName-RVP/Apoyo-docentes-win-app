Apoyo Docentes - Windows App
Aplicacion de escritorio (WPF, .NET 8) para automatizar cargas horarias docentes, directorio de contactos, envio de correos y consulta de horarios.
Windows 10/11

Pasos:
Descargar el .zip desde GitHub.
Descomprimirlo.
Ejecutar ApoyoDocentes.exe.
Si se usara Gmail o Google Sheets, vincular el archivo client_secret.json desde la app.
Para Plataformas
Windows 10/11

Funcionalidades principales:
Carga de Excel con tabla general
Generacion de cargas por docente
Directorio de contactos (SQLite)
Envio de correos usando (Gmail API)
Horarios docente desde Google Sheets
Tema claro/oscuro

Google APIs (Gmail + Sheets)
Estas APIs deben habilitarse manualmente en Google Cloud. No se pueden activar automaticamente desde la app.
1) Crear proyecto en Google Cloud
Ve a Google Cloud Console.
Crea un proyecto nuevo (o usa uno existente).
2) Habilitar APIs

En el proyecto:
Habilita Gmail API
Habilita Google Sheets API
3) Configurar pantalla de consentimiento (OAuth)
En "OAuth consent screen" selecciona tipo External (o Internal si es cuenta institucional).
Completa nombre de la app y correo de soporte.

Agrega los scopes:
Gmail: https://www.googleapis.com/auth/gmail.send
Sheets: https://www.googleapis.com/auth/spreadsheets.readonly
Agrega los usuarios de prueba (si aplica).
4) Crear credenciales OAuth
Ve a "Credentials" ? "Create Credentials" ? "OAuth client ID".
Tipo de aplicacion: Desktop app.
Descarga el archivo JSON (client_secret.json).
5) Vincular la cuenta en la app
Abre la app ? Configuracion ? Vincular cuenta Gmail.
Selecciona el archivo client_secret.json.
Se abrira el navegador para autorizar.

Notas
El archivo de base de datos se guarda en %AppData%\AppParaUniversidad\app.db
Las credenciales de Google se configuran desde la app
